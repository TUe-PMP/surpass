# General examples

These notebooks introduce the SURPASS physical modules in increasing order of
coupling. They are intended as editable starting points rather than calibrated
predictions for a particular experiment.

| Notebook | Main use case |
|---|---|
| `01_bulk_model_validation.ipynb` | Equilibrium statistics, transport, and recombination |
| `02_optical_generation.ipynb` | Transfer-matrix pump absorption and generation |
| `03_steady_state_1d_transport.ipynb` | Steady-state ambipolar diffusion |
| `04_fixed_charge_surface_coupling.ipynb` | Fixed-charge surface boundary |
| `05_interface_charge_and_pinning.ipynb` | Interface charge and Fermi-level pinning |
| `06_spatial_band_profiles.ipynb` | Band bending and space-charge profiles |
| `07_transient_transport_trpl.ipynb` | Transient carrier transport and internal PL |
| `08_spectral_escape_recycling.ipynb` | Spectral escape and local photon recycling |
| `09_experimental_trpl_detection.ipynb` | Pulse trains and detector-response modelling |

Run notebooks from the repository root or install SURPASS into the active
environment before opening them.
